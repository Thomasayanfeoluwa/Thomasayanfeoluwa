## Featured Projects

### 🏭 SWaT Industrial Anomaly Detection

An end-to-end anomaly-detection study using multivariate telemetry from the Secure Water Treatment (SWaT) testbed. The project compares nine detection methods and deploys a historical-replay monitoring prototype using the selected Temporal Convolutional Network (TCN) autoencoder.

<p>
  <a href="https://swat-anomaly-monitor-system.onrender.com"><img src="https://img.shields.io/badge/Live_Demo-7C3AED?style=for-the-badge&logo=render&logoColor=white" alt="SWaT live demo" /></a>
  <a href="https://youtu.be/KsfToradzcA"><img src="https://img.shields.io/badge/Video_Demo-FF0000?style=for-the-badge&logo=youtube&logoColor=white" alt="SWaT video demonstration" /></a>
  <a href="https://github.com/Thomasayanfeoluwa/multivariate-telemetry-anomaly-detection"><img src="https://img.shields.io/badge/Source_Code-181717?style=for-the-badge&logo=github&logoColor=white" alt="SWaT source code" /></a>
</p>

**What it demonstrates**

- **Normal-only model training:** the TCN autoencoder is trained on normal-operation data; attack labels are reserved for offline evaluation and retrospective analysis.
- **Reproducibility and inference parity:** a seven-test feasibility audit rescored 181,031 sequences with a maximum absolute score difference of `5.215 × 10⁻⁸` and zero alert-flag disagreements.
- **Event-level evaluation:** 28 of 36 evaluated labelled attack scenarios were detected. On validation data, 2,528 false-positive observations were grouped into 73 false-alarm periods.
- **End-to-end application engineering:** FastAPI and PyTorch backend, React and TypeScript frontend, sensor visualisation, alert history, feature attribution, and historical replay at up to 50× speed.

**Core technologies:** Python · PyTorch · Scikit-learn · FastAPI · React · TypeScript · Vite · Pandas

> **Scope and limitation:** The app replays historical testbed measurements. It is a research and monitoring prototype, not a live-plant control system. An alert is a signal for investigation, not proof of a cyberattack, equipment failure, or unsafe process condition.

### 🎬 TrailerTV — Movie Recommendation System

A full-stack movie discovery application that recommends related films using content similarity and provides review sentiment analysis and trailer access.

<p>
  <a href="https://movie-recommender-mu4e.onrender.com/home"><img src="https://img.shields.io/badge/Live_Demo-7C3AED?style=for-the-badge&logo=render&logoColor=white" alt="TrailerTV live demo" /></a>

- **Application engineering:** Flask backend, PostgreSQL persistence, SQLAlchemy, TMDB API integration, and a deployed web interface.

**Core technologies:** Python · Flask · Pandas · Scikit-learn · FAISS · PostgreSQL · SQLAlchemy · TMDB API

## How I Approach ML Engineering

I treat machine learning projects as complete systems rather than isolated models.

```text
Data & Validation
        ↓
Feature Engineering
        ↓
Model Development & Experimentation
        ↓
Evaluation, Error Analysis & Reproducibility
        ↓
API and Application Integration
        ↓
CI/CD and Cloud Deployment
        ↓
Monitoring, Observability & Continuous Improvement
```

I aim to make model behaviour measurable, deployment workflows reproducible, operational behaviour observable, and system limitations clear to the people using the results.
